# Guía del equipo

1. Abre el acceso del equipo o la app instalada. Utiliza tu cuenta personal de Supabase Auth.
2. Cambia una contraseña temporal desde «Mi cuenta». La aplicación verifica la actual antes de actualizarla en Auth.
3. Solo verás las herramientas que permita tu rol. Si falta una herramienta necesaria, contacta con el propietario; no compartáis credenciales.
4. Encargados pueden gestionar carta y contenido. Camarero/cocina todavía no tienen módulos operativos activos; los apartados aplazados no se sustituyen por datos de ejemplo.
5. Para editar un producto, revisa nombre, categoría, precio, disponibilidad y traducciones. No completes alérgenos o ingredientes por suposición.
6. Una fotografía subida es pública. Espera la confirmación y guarda el formulario para asociarla.
7. Espera el mensaje de guardado; si hay un error o conflicto, no supongas que se ha confirmado el cambio. Recarga y comprueba el estado antes de repetir.
8. Sin conexión, las acciones quedan deshabilitadas. No existe una cola de cambios offline ni operaciones confirmadas sin servidor.
9. Utiliza botones y teclado: foco visible, Tab para avanzar, Escape para cerrar fichas/confirmaciones. En tablet los formularios se adaptan al ancho disponible.
10. Cierra sesión antes de dejar un dispositivo compartido. Si ha caducado, vuelve a identificarte; no se permite usar una vista guardada como autorización.

La instalación depende del navegador y del sistema. «Solicitud de instalación aceptada» no implica que se haya completado un proceso nativo del sistema operativo. Si no aparece el botón, consulta las opciones del navegador.

Para cuenta bloqueada, contraseña olvidada, permisos o incidencias persistentes, contacta con el propietario. No publiques capturas con correos internos, tokens, formularios o datos privados.
